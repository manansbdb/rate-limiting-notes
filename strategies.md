# Strategies / Estratégias

## English
- **Fixed window** — simple counters per interval; can burst at edges.
- **Sliding window** — smoother; slightly more complex.
- **Token bucket** — allows controlled bursts.
- **Leaky bucket** — steady outflow rate.

Scope keys by API key, user id, IP, or route. Prefer user/API key over raw IP when authenticated.

## Português
- **Janela fixa** — contadores simples por intervalo; pode haver burst nas bordas.
- **Janela deslizante** — mais suave; um pouco mais complexa.
- **Token bucket** — permite bursts controlados.
- **Leaky bucket** — taxa de saída estável.

Scope keys por API key, user id, IP ou rota. Prefira user/API key em vez de IP cru quando autenticado.
